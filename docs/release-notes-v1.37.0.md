## Glue Desktop 1.37.0

First public macOS release of Glue Desktop for Apple Silicon.

### Highlights

- local-first Claude Code workflow with both CLI and desktop UI
- DMG package for macOS arm64
- automatic local backend startup from the desktop flow
- cleaned up Glue branding across the packaged app
- direct local launch flow without the old hanging startup screen

### Notes

- this release targets macOS on Apple Silicon
- the app is not code signed or notarized yet
- local model serving depends on your existing `claude-code-local` installation
